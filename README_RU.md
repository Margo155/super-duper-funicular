# Oddplot — комплект для второго выпуска

**Монетка, которая ускоряет огромные часы**

Рабочий английский заголовок: **A Penny Makes This Giant Clock Run Faster**.
Заказ для производства: полный новый шортс, 1080×1920, 30 fps. Номинальная раскадровка — 54 секунды. Текст — 153 произносимых слова; расчёт при 195 словах/мин и шести секундах визуальных пауз даёт около 53 секунд. Это оценка; записанной озвучки нового выпуска в комплекте ещё нет.

## Передача в производство

1. Передай ZIP в производственный проект Oddplot, в задачу второго выпуска. Если задача принимает только отдельные файлы, распакуй комплект и передай его содержимое доступным способом.
2. Вставь PROMPT_FOR_CODEX.txt в задание.
3. Новому эпизоду нужна отдельная папка. Принятую V3 первого теста сохраняем как эталон, а исходный риг/настройки используем повторно, если они доступны в производственном проекте.
4. В комплект уже вложены MP4 принятой V3, три контрольных кадра и исходный аватар. Файлы из другого чата не считаем автоматически доступными.
5. Результат, который должен сделать производственный Codex: полный мультфильм с новой озвучкой, а не очередной тест начала и не копия старого ролика.

## На что обратить внимание

- Монета меняет темп часов, а не мгновенно переводит стрелки.
- Прибавление старого пенни — около +0,4 секунды в сутки относительно прежнего хода.
- Важны положение монеты и распределение массы. Металлический стержень не укорачивается.
- У героя ноги и обувь всегда соединены; при сгибании коленей ботинки не остаются отдельными предметами на полу.
- Субтитры подняты относительно V3; итоговые таймкоды строятся по реально записанному голосу.

Этот архив содержит сценарий, производственное задание, эталоны и инструменты контроля. Готового видео и новой записанной озвучки эпизода 002 здесь нет.
