# Oddplot — комплект для первого производственного теста

История №001: **They Flooded This Vessel on Purpose**. Реальная основа —
исследовательская платформа FLIP. Текущий объём производства — **только первые
15 секунд**, 9:16, 30 fps. Полный сценарий приложен для контекста.

## Как передать

1. Скачайте ZIP и откройте задачу Codex Cloud для Oddplot.
2. Если в вашей версии есть прикрепление файлов, приложите ZIP к задаче.
   Если ZIP не принимается, распакуйте и приложите доступные отдельные файлы.
3. Если задача получает материалы из GitHub/GitLab, поместите распакованный
   каталог в подключённый репозиторий и укажите Codex его путь. Для первой
   облачной задачи репозиторий не всегда обязателен: это зависит от доступного
   окружения. Не создавайте репозиторий только ради этого архива, если файлы
   уже можно передать непосредственно в задачу.
4. Вставьте содержимое `PROMPT_FOR_CODEX.txt` в поле задания.
5. Продолжайте проверку и исправления этого теста в той же облачной задаче.

Этот пакет ещё не содержит отрендеренного мультфильма или записанного голоса.
Он содержит утверждённые исходные материалы и конкретное техническое задание.
Готовность к рендеру и доступность TTS должен проверить производственный Codex.
Файлы в другом чате не следует считать доступными, пока Codex не подтвердил,
что нашёл их в своей задаче.

## Что внутри

- `PROMPT_FOR_CODEX.txt` — готовое стартовое сообщение.
- `AGENTS.md` — короткие постоянные инструкции для производственного проекта.
- `PROJECT_BRIEF.md` — бренд, персонаж, технология и результаты теста.
- `TEST_15S_STORYBOARD.md` — четыре плана на первые 15 секунд.
- `EPISODE_001_SCRIPT.md` — весь утверждённый английский текст; полное видео
  в этой задаче не производится.
- `audio/TEST_15S_VOICEOVER.txt` — только произносимые слова теста.
- `subtitles/TEST_15S_DRAFT.srt` — черновая сетка титров, требующая выравнивания
  по фактически синтезированному голосу.
- `assets/hero_reference.png` — оригинальный утверждённый аватар как эталон лица.
- `STYLE_BIBLE.md` — полный ранее выполненный анализ 20 роликов-референсов.
- `FACTS_AND_SOURCES.md` — фактические опоры и постановочные допущения.
- `MANIFEST.json` — перечень файлов, размеры и SHA-256.

## Порядок работы

Проверка среды → короткая проверка рендера и TTS → исходная сцена и герой →
озвучка → движение и монтаж → 15-секундное MP4 → проверка → исходники и инструкция
повторного запуска. Локальный тест рендера — техническая проверка, не повод
останавливаться и ждать отдельного разрешения на уже заказанный 15-секундный тест.

В настройках окружения может потребоваться доступ к источникам установки
программ или к сервису озвучки. Codex должен назвать конкретный блокер, если
доступа нет. Платные сервисы без заданного бюджета не подключать автоматически.
